# 方块盒子 BlockBox

> 不用敲指令、不用改配置，十分钟搭起你自己的 Minecraft 服务器。
> 一个 Windows 桌面软件，把开服从「查教程改文件」变成「点几下」。

## 这是什么

**方块盒子**是一个 Minecraft 服务器控制台。它不替代服务端，而是把"开服"这件事
从命令行和配置文件里搬到一个界面上：

- **新手**：全程不用打开任何文件夹、不用输任何命令
- **老手**：常用功能都在一屏里，省掉来回找文件的时间

界面用我的世界官方素材做成（方块贴图、粒子特效、音效、HUD 图标），
操作逻辑按现代软件的习惯来，看着像游戏、用着像工具。

## 主要功能

### 🚀 一键搭服
选个版本 → 点开始 → 自动下载 Java、下载服务端、写好配置、装上性能优化模组。
支持 **Fabric（模组服）/ Paper、Purpur（插件服、小游戏服）/ 原版**。
全程 3~10 分钟，不用你改任何文件。

### 📊 实时监控
CPU、内存、GPU、TPS、在线玩家、各维度实体数量（精确到每种生物多少只）。
服务器卡顿时一眼看出是谁在吃资源。

### 🗺 三维地图
主世界 / 下界 / 末地三个维度，按存档方块渲染。
支持**一键渲染全图**，**未探索区域会标出来**，还能以出生点为中心渲染一半。

### 👁 观战
按存档方块算出玩家眼前的画面 —— 看得到地形和建筑，也看得到：
- **附近实体**（玩家 / 敌对生物 / 动物 / 掉落物，带距离标记）
- **他正在看哪个方块**、游戏内时间（白天/夜晚）
- **官方图标的血量、饱食度、状态效果、手持物品**

### 🧩 模组 / 插件
- **推荐模组**：8 个公认好用的性能优化模组，一键装
- **主流模组**：按下载量实时列出 14 个，不用搜，看到想装的直接点
- **收藏 + 一键装回**：开新服务器时不用再一个个找
- **模组详情**：点一下就能看简介、支持的版本、下载量，还有 MC百科 / 官网链接
- **整合包**：搜 Modrinth 整合包，一键把**服务端该装的模组全下好**（客户端专用的自动跳过，`overrides` 里的配置也一起应用）
- 插件端还带**插件专区**

### 🌐 内网穿透
按**免费 / 收费**分类收录主流服务（Tailscale、EasyTier、樱花 frp、OpenFrp、playit.gg…）。
自动识别**局域网 IP / 公网 IP / IPv6**，一键复制地址发给朋友，
还能**检测穿透地址是否真的能进**（用 Minecraft 协议真连一次）。

### 📢 服务器公告
三种模式，可开可关：**进服欢迎**（每次）、**首次进服**（同一个人只发一次）、
**定时轮播**（间隔 5 秒 ~ 24 小时自由设，小游戏服刷倒计时也够用）。

### 🔄 版本实时更新
读 **Mojang 官方版本清单**，帮你判断落后多少版，
选好目标版本点一下就能把服务器更新过去（自动备份旧服务端）。

### 🧰 百宝箱 + 内存优化
- **设备内存**：整机内存监控 + 一键回收（实测能释放 3 GB 左右）
- **清理工具**：历史日志 / 崩溃报告 / 地图缓存 / 旧备份 / 下载残留
- **删除服务器**：三种删法 + 回收站 + 多重确认（控制台自己不会被误删）

### 其他
备份与日志 · 服务器配置（含 JVM 预设）· 白名单/OP 管理 · 快捷指令栏 ·
控制台日志中文化 · 成就与彩蛋 · 首次运行自动检测本机服务器

## 系统要求

| | |
|---|---|
| 系统 | Windows 10 / 11（64 位）|
| 内存 | 2 GB 以上（开服建议给服务端 4 GB 以上）|
| 网络 | 能上网（下服务端和模组要用）|
| 其他 | **Java 和 Node 已经随包自带**，不用自己装 |

### 两个版本，按需选

| 版本 | 体积 | 说明 |
|---|---|---|
| **标准版** | 37 MB | 用系统自带的 WebView2 内核（Win10/11 基本都有），下载快 |
| **完整版** | 272 MB | 自带内核，老系统 / 精简版 / 内网机器也能双击即用 |

功能完全一样，代码同一套。

## 怎么用

1. 下载 zip，解压到你想放服务器的地方（建议单独一个文件夹）
2. 双击 `方块盒子.exe`
3. 第一次打开会自动检测本机有没有服务器：
   - **有** → 问你要不要接管
   - **没有** → 三步教你搭一个
4. 搭好后点顶栏「启动服务器」，等它显示"已就绪"就能进游戏了
